# 🏦 Bank Management System

A complete C++ banking application built with Object-Oriented Programming principles.

## 📋 Features

- **18 Menu Options** – Full banking operations
- **Two Account Types** – Savings (5% interest) & Current (GHC 1,000 overdraft)
- **Transaction History** – Every deposit, withdrawal, and transfer logged
- **File Persistence** – Save/load data to text file
- **Customer Management** – Register, search, edit, delete
- **Duplicate Prevention** – Prevents duplicate customer registration
- **Account Reactivation** – Close and reopen accounts
- **Interest Calculation** – View interest on Savings accounts

## 🛠️ Technology

- **Language:** C++17
- **Paradigm:** Object-Oriented Programming
- **Key Concepts:** Inheritance, Polymorphism, Encapsulation, Abstraction

## 🚀 How to Run

1. Go to `bin/`
2. Double-click `bank_file.exe` (with file storage) or `bank_memory.exe` (in-memory only)

## 📁 Project Structure
BankManagementSystem/
├── bin/ → Executables (.exe)
├── data/ → Data persistence (bank_data.txt)
├── include/ → Header files (.h)
└── src/ → Source files (.cpp)
